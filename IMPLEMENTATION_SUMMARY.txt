### Quick Version (5 minutes)

1. **Create GitHub repo:** https://github.com/new → name it `medicine_app` → Create
2. **Upload files:**
   - Click "Add file" → "Upload files"
   - Drag drop all files from medicine_app folder
   - Commit
3. **Enable Pages:**
   - Settings → Pages
   - Source: Deploy from a branch
   - Branch: main / (root)
   - Save
4. **Access site:**

## Security & Disclaimers

⚠️ **Important Notes:**

1. **No Real Payments** – This is a demo/prototype. Does not actually charge customers.
2. **No Prescription Verification** – Assumes all medicines are available without prescriptions (not realistic).
3. **No User Accounts** – Guest checkout only, no account creation or login.
4. **Demo Database** – 20 hardcoded medicines, not real inventory management.
5. **Client-Side Only** – No backend server, no database, no email confirmation.

**For Production E-Commerce:**
- Add backend API (Node.js, Python, Java)
- Integrate payment gateway (Razorpay, Stripe)
- Implement user authentication
- Add prescription verification
- Comply with pharmaceutical regulations
- Encrypt sensitive data

**See ARCHITECTURE.md and README.md for detailed security considerations.**
